# Flex Sensor using Arduino

## Description
This project reads the bending of a flex sensor using Arduino Uno and displays the sensor value on the Serial Monitor.

## Components
- Arduino Uno
- Flex Sensor
- 1 kΩ Resistor
- Jumper Wires

## Connections
- Flex Sensor → A0
- 1 kΩ Resistor → GND

## Working
The resistance of the flex sensor changes when it bends. Arduino reads the analog value and prints it on the Serial Monitor.

## Output
Flex Value: 120
Flex Value: 340
Flex Value: 650
