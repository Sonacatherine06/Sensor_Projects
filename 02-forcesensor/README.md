# Force Sensor using Arduino

## Description
This project measures the pressure applied to a Force Sensor (FSR) and displays the value on the Serial Monitor.

## Components
- Arduino Uno
- Force Sensor
- 1 kΩ Resistor
- Jumper Wires

## Connections
- Force Sensor → A0
- 1 kΩ Resistor → GND

## Working
The sensor changes its resistance according to the applied force. Arduino converts the analog value and displays it.
