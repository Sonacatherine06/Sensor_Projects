# Microphone Sensor using Arduino

## Description
This project measures sound intensity using a microphone sensor and displays the readings on the Serial Monitor.

## Components
- Arduino Uno
- Microphone Sensor
- Jumper Wires

## Connections
- OUT → A0
- VCC → 5V
- GND → GND

## Working
The Arduino continuously reads the analog sound value and displays it on the Serial Monitor.

## Output
Sound Value: 120
Sound Value: 380
Sound Value: 650
