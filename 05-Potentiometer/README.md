# Potentiometer using Arduino

## Description
This project reads the position of a potentiometer and displays the analog value on the Serial Monitor.

## Components
- Arduino Uno
- Potentiometer
- Jumper Wires

## Connections
- Middle Pin → A0
- Side Pins → 5V and GND

## Working
Rotating the potentiometer changes the output voltage. Arduino reads the value and displays it.

## Output
Value: 0
Value: 512
Value: 1023
