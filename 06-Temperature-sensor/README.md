# Temperature Sensor using Arduino

## Description
This project measures temperature using a TMP36 temperature sensor and displays the temperature in Celsius.

## Components
- Arduino Uno
- TMP36 Temperature Sensor
- Jumper Wires

## Connections
- VCC → 5V
- VOUT → A0
- GND → GND

## Working
Arduino converts the sensor voltage into temperature and prints the temperature on the Serial Monitor.

## Output
Temperature: 26.5 °C
Temperature: 28.1 °C
Temperature: 30.0 °C
