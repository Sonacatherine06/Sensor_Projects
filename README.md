# Sensor Projects Collection

![Arduino](https://img.shields.io/badge/Arduino-Uno-333333)
![C++](https://img.shields.io/badge/Language-C++-00534E)

A collection of 10 Arduino Uno sensor projects, each demonstrating a different type of sensor and how to interface it with an Arduino.

## Projects

| # | Project | Sensor | Pin |
|---|---------|--------|-----|
| 01 | [Flex Sensor](01-flex-sensor/) | Flex Sensor | A0 |
| 02 | [Force Sensor](02-forcesensor/) | FSR | A0 |
| 03 | [LDR Automatic Light](03-LDR-Automatic-Light/) | LDR | A0 |
| 04 | [Microphone Sensor](04-Microphone-sensor/) | Sound Sensor | A0 |
| 05 | [Potentiometer](05-Potentiometer/) | Potentiometer | A0 |
| 06 | [Temperature Sensor](06-Temperature-sensor/) | TMP36 | A0 |
| 07 | [PIR Sensor](07-PIR-sensor/) | HC-SR501 | 2 |
| 08 | [Ultrasonic Sensor](08-ultrasonic-sensor/) | HC-SR04 | 9, 10 |
| 09 | [Tilt Sensor](09-Tilt-sensor/) | Tilt Sensor | 2 |
| 10 | [Push Button](10-Push-button/) | Push Button | 2 |

Each project folder contains its own README, source code, and media files.

## Technologies

- **Language:** C/C++ (Arduino framework)
- **Board:** Arduino Uno (ATmega328P)
- **IDE:** Arduino IDE 1.8+ / 2.x

## Hardware Requirements

- Arduino Uno and USB cable
- Breadboard and jumper wires
- Sensors listed per project

## Installation

1. Open the project folder of your choice.
2. Read the project-specific README for wiring instructions.
3. Assemble the circuit on a breadboard.
4. Connect the Arduino to your computer.
5. Upload the code using Arduino IDE.
